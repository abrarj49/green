# Vercel Environment Variables Setup Guide

Ye file aapke Vercel project ke tamam zaroori environment variables provide karti hai.

---

## 🚀 Fast Method (Single Copy-Paste):

Vercel par ek feature hai jisme aap **sare variables ek sath paste** kar sakte hain:
1. **Vercel Dashboard** open karein -> Apna project select karein.
2. Top tabs me se **"Settings"** par click karein.
3. Left sidebar se **"Environment Variables"** par click karein.
4. "Key" wale pehle input box par click karke **niche diya gaya poora block copy karke paste kar dein** (Vercel automatically sab alag-alag keys me divide kar dega):

```env
NEXT_PUBLIC_SITE_URL=https://green-solution-site-website.vercel.app
ADMIN_EMAIL=admin@greensolutionksa.com
ADMIN_PASSWORD_HASH=$2b$10$ZnTtVGEh9I1DfbTb87WV6ukB5OU15MaEf652fuppuoRWyeZuVA/16
JWT_SECRET=green-solution-jwt-secret-key-prod-2026-ksa-super-secure
ADMIN_NOTIFICATION_EMAIL=chhameed@greensolutionksa.com
RESEND_API_KEY=re_test_key
NEXT_PUBLIC_GA_ID=
```

5. **"Save"** par click kar dein.
6. Uske baad **Deployments** tab me ja kar latest deployment ke three dots `...` par click karke **"Redeploy"** dabayein taake naye env variables apply ho jayein!
